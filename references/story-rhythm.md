# 参考样本与节奏选择

## 依据与范围

用户指定参考账号：[金漫漫](https://www.xiaohongshu.com/user/profile/6954670c000000003801f1d0)。2026年10月30日通过浏览器实看以下两篇，每篇18页，完整翻阅第1—18页。以下是样本概括，不是对账号全部作品的统计，也不是作者自述的创作规则。

- [那次爬山，我对他瞬间死心](https://www.xiaohongshu.com/explore/6adde2c5000000002b00fd00)：以一次出游为完整事件，前段建立关系里的信任，中段让同一种亲密行为产生不同含义，后段交代当事人的反应与选择。一个场景持续多页，通过动作进展、身体感受、对白与局部特写改变节奏。
- [半夜他伸来的手，让我觉得嫁对了](https://www.xiaohongshu.com/explore/6ae1e682000000002303065b)：从当下一个细小的照顾动作开始，展开平常相处的片段，再引入生活处境的变化，最后回到当下。关系的重量来自日常细节累积，没有必须反转的要求。

共同可借鉴的做法：第一人称回述、具体生活情境、口语短句、一页一个主要叙事单位、大字文案配单幅场景、人物画面与物件或动作特写交替。标题点出具体情境及情绪方向，正文保留让人理解这个判断的过程。

借鉴抽象方法创作新的故事，不沿用样本独有的事件组合、关键对白与结尾，再只替换名字或地点。单页字数建议来自本技能设计，不是样本的精确字数统计。日后链接不可访问时，使用已记录的有限观察，不得声称本轮重新读过。

## 节奏地图：18页长篇示范，可压缩为更少页数

本技能默认不超过18页，以下页段不是最低篇幅或固定配额。按当前故事选择页数，合并不必要的铺垫和过渡；悬疑故事可以停在异常结果，不必解释机制。

### A. 一个事件逐步改变判断

适合一次相处、争执、童年经历、笑话或误会。

| 页段 | 可以承担的任务 | 写作判断 |
| --- | --- | --- |
| 01—03 | 进入情境，建立原先的期待与关系 | 读者理解当事人为什么参与或相信 |
| 04—06 | 事情发生，埋下相关细节 | 用行动推进，避免连续背景介绍 |
| 07—10 | 判断遇到新情况，人物尝试回应 | 不必是冲突，也可好奇或意外的照顾 |
| 11—14 | 关键行为及后果，情绪或理解变化 | 高峰可以是轻声的一句话，无需大事故 |
| 15—17 | 人物回应、选择或补救 | 给结果留下行动过程，不突然宣布结局 |
| 18 | 一个结果、动作或具体感受 | 回答开头问题，或改变早先细节的含义 |

### B. 当下小事牵出回忆

适合亲情、友情、怀旧、失去后的记忆、平常生活中的被理解感。

| 页段 | 可以承担的任务 | 写作判断 |
| --- | --- | --- |
| 01—03 | 当下动作、物件或对白触发感受 | 先发生一件事，避免开场抒情 |
| 04—08 | 用过去的相关小事建立关系 | 累积含义，避免无关的幸福清单 |
| 09—12 | 处境、时间或人物态度改变 | 可是长大、搬家、需求变化，无需灾难 |
| 13—15 | 一次选择或重新理解让细节有分量 | 不临时增加未经铺垫的秘密 |
| 16—17 | 回到当下，让细节再次出现 | 时间转换清楚，相似细节获得新含义 |
| 18 | 当下的行动或心里话 | 留余味，不重复解释已成立的感受 |

适合前半段揭示、后半段展开如何面对的故事，就让揭示提前，不为表格强行保密到最后。

## 扩写与分页的实际判断

只有结论时，补出让结论成立的经历。例如“我终于敢和妈妈说不”，选择一次具体请求，写以前如何应对、这次遇到什么、尝试怎样表达、妈妈如何回应、主角如何承担结果，不自动增加全家决裂、住院或彻底和解。

只有一个动作时，可以拆成有差异的单位：动作前的期待、动作本身、对方的回应、主角的误解或发现、之后的新行动，不能把相同感受换五种说法。

检查“删掉这页会怎样”：删掉会使行动难懂、损失重要证据、失去情绪停顿或破坏呼应，这页有作用；删掉只会少一句同义感慨，就应重写。
